# Hand ornament ribbon layout

Fit the wrist strip, dorsal bridge and finger loop independently before joining. The layout is three flat cuts; physical fit and all hand-attachment joins remain unverified.

Original draft. Native representation: FC flat pattern / construction guide in millimetres. `length` and `width` are flat construction dimensions, not a promised fitted body size. The generator declares every matched sewn relationship it checks; hand joins, gathers, adhesive, hardware and retention remain unverified. The SVG, DXF, PDF and JSON derive from the same pattern. Marked internal cuts must be interpreted using the instructions above.

Unranked jewellery enabler for Jewelry Studio; no FC band slot is claimed. Census compared 516 soft manifests and the FC100–500 bands. Existing `watch-strap`, `cord-end-notion` and garment cuffs have different output interfaces; this family is the construction described above. Reviewer must confirm census and route before publication.

Provenance: original first-principles draft, not copied from a cultural garment or designer pattern. CERN-OHL-W-2.0 under the commons root licence. Four-language labels are draft translations; human language review is pending (including French and Portuguese). No reviewed-translation attestation or public acceptance is claimed.

Making: select material, inspect pattern and marked operations, make a sample, resolve attachment and wearer fit before use. Native outline/seam checks do not establish physical strength, comfort or material behaviour.

## Piece dispatch

`target_piece="pattern"` exports the complete set. `wrist`, `bridge`, `finger` are individual-piece targets; an unknown target fails. The complete construction is checked before selection. A subset retains only seams whose two sides are present; omitted cross-piece seams are counted explicitly in native `metadata.dispatch`. Subset BOM rows cover only the selected piece. Full-set geometry and seam declarations are preserved. The per-cartridge `tests/verify_native.py` checks default and changed full sets, every single-piece branch, retained/omitted seam scope, quantities and invalid-target rejection through the native runner.
