# Quilted Button-in Liner Jacket

The warm layer that lives inside a **three-in-one coat**: a light quilted jacket with its own
front buttons, plus a row of loops that button into a host shell so the two travel as one in
winter and separate in spring.

Part of the **Fashion Cabinet Commons** (FC-400, rank #377 — outerwear).
**Yantra4D-bridged** (`sew-through-button`). Official visualizer and configurator:
[Fashion Cabinet](https://fashioncabi.net).

## Why it earns its rank

A three-in-one coat is really two garments sold at a markup because the liner and shell are
proprietary to each other. Drafting the liner to a standard button-in pitch means one warm
layer can serve several shells — a wardrobe of one liner and a few outer coats.

## Pieces

`front` (cut 2 mirrored, own-button placket + button-in loops) + `back` (cut 1 on fold) +
`sleeve` (one-piece quilted, cut 2 mirrored).

## The seam that solves

The button-in loops must land at the **same pitch as the host shell's buttons**, or the liner
hangs crooked inside the coat. The loop pitch is solved from the measured button run and the
requested count, recomputed so the row lands exactly on both end clearances — the same
land-exactly discipline the magnetic-placket shirt uses. The quilting channel count is derived
so the channels divide the body evenly rather than leaving a runt channel at one edge. The
sleeve cap is bisected against the measured armholes; the back neck width is solved from the
front's measured shoulder with the flatten clamp.

## Construction notes

Bar-tack each button-in loop — they carry the liner's weight inside the coat. Match the marked
quilting channels to a bought quilt's grid if you use pre-quilted nylon. Use down-proof quilt if
you fill it yourself.

## Cross-commons bridge
