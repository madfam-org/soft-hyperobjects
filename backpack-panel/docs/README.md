# Backpack (Panelled)

A simple **panelled rucksack**: a wrap body (front + base + back folded at the base), a
long side/base gusset, a top flap that buckles shut, and two shoulder straps. The flap +
strap buckles bridge to the Yantra4D [`strap-buckle`](https://app.yantra4d.com).

Part of the **Fashion Cabinet Commons** (FC-200, Lane 3 — accessories). Official
visualizer and configurator: [Fashion Cabinet](https://fashioncabinet.app).

## Pieces

Body + side/base gusset + top flap + two shoulder straps.

## Parameters

`pack_width`, `pack_height`, `pack_depth`, `flap_drop`, `strap_width` (sizes the Yantra4D
buckle), `strap_length`.

## Cross-commons bridge

`notion.hardware_ref` → `strap-buckle`, mapping `strap_width → webbing` (one flap closure
+ two strap adjusters).
