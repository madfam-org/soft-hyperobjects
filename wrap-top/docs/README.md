# Wrap Top

A surplice wrap top: two front panels cross in a deep V and tie at the side (one inseam tie through the side seam, one outside), over a plain back — the top-length counterpart to the wrap-dress. Each front extends past centre front by a crossover so they overlap; shoulder + side edges match the back, so both seams balance by construction. A soft-goods garment — no hardware. FC-200 long-tail (silhouette gap).
