# Trail-running vest pack

The trail runner's hydration vest: a light **stretch-mesh** vest that hugs the torso like a
second skin, carries soft flasks in front pockets, and closes across the sternum on side-release
buckles on adjustable webbing.

Part of the **Fashion Cabinet Commons** (FC-500, rank #451 — active_swim).
**Yantra4D-bridged** (`side-release-buckle`). Official visualizer and configurator:
[Fashion Cabinet](https://fashioncabi.net).

## Why it earns its rank

A hydration vest is a wearable pack, and the reason a bad one ruins a run is bounce: any slack
between the load and the body turns every stride into a small blow to the sternum. Cutting the
vest at negative ease and pulling the front tight to a measured chest removes the bounce at its
source.

## Pieces

`front` (cut 2, flask pockets) + `back` (cut 1 on fold, mesh) + `strap` (cut 4, sternum webbing).

## The seam that solves

The vest is cut at **negative ease** so it grips, and the front pocket depth is **clamped under
0.75× the front length** so it never runs past the hem, whatever the sliders do. The back neckline
and shoulder are drafted so each front shoulder matches the back shoulder by construction.

## Construction notes

Cut a breathable stretch power mesh at negative ease with ripstop-faced front pockets for soft
flasks. Flatlock every seam. Set the sternum webbing with the side-release buckles across the
chest.

## Cross-commons bridge

Yantra4D **`side-release-buckle`** (`notion.hardware_ref`): its `webbing_w` (a webbing-channel
flange parameter) is driven by this vest's `webbing_w`, the same parameter that drives the
`sternum_strap` interface — the dimensional handshake the hardware lane enforces.
