# Mesh Delicates Wash Bag

The zip-top mesh bag that keeps a bra's hooks off a sweater and a sock out of the machine's
gasket: two mesh panels box-stitched on three sides, the fourth closed by a **zipper** whose
pull tucks under a small flap so it cannot snag or scratch the drum.

Part of the **Fashion Cabinet Commons** (FC-400, rank #368 — care & keeping).
**Yantra4D-bridged** (`zipper`). Official visualizer and configurator:
[Fashion Cabinet](https://fashioncabi.net).

## Why it earns its rank

A snagged sweater or a sock lost to the gasket is a garment killed by laundry, and the shop
answer is a throwaway mesh bag that frays in a season. This one is drafted around a printable
zip and a solid-bound mouth, so the zip can be replaced rather than the whole bag binned.

## Pieces

`panel` (one mesh face, cut 2) + `flap` (the pull-tuck cover, cut 1).

## The seam that solves

A mesh bag is dimensionally simple, but the **zip tape must run the full measured mouth** or
the corners gape and small items escape. The panel `mouth` edge and the zipper's `zip_length`
are the same `bag_width` — that shared dimension is the handshake the hardware lane enforces.
The pull-tuck flap is floored at 45 mm so it can never be cut too short to hide the parked
pull that would otherwise scratch the drum.

## Construction notes

Bind the mouth in solid fabric before setting the zip — the teeth tear straight out of raw
mesh. Zig-zag every seam so it flexes wet without splitting. Set the pull-tuck flap at the
closed end so the parked pull sits under it.

## Cross-commons bridge

Yantra4D **`zipper`** (`notion.hardware_ref`): its `zip_length` is driven by this bag's
`bag_width` — the same parameter that drives the `zip_mouth` interface, so the garment's edge
and the hardware's tape edge are dimensionally coupled.
