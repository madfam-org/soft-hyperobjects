# D-Ring / Slider

A **Yantra4D-bridged notion** (a Group-B **co-creation**) — the 2-D placement guide for
the flat-bottomed D-ring loop that anchors straps and webbing on a bag or overall. Fashion Cabinet owns the placement; the finding **solid** is the Yantra4D
[`d-ring`](https://app.yantra4d.com) cartridge, a fastener FC needed that was co-created
as a Yantra4D object, referenced through `notion.hardware_ref`.

Part of the **Fashion Cabinet Commons** (FC-200, Lane 1 — findings). Official visualizer
and configurator: [Fashion Cabinet](https://fashioncabinet.app).

## The cross-commons bridge

`notion.hardware_ref` → `d-ring`. The bridge is **dimensional**: the guide's placement
line and the finding's `flange` cdg_interface share driving parameters, so
`verify_hardware_links` enforces name resolution **and** the shared-dimension handshake.
