# Cowl-Neck Top

A relaxed top whose front neckline rises above the shoulder into a self-facing that folds back into a soft cowl — no separate collar. The front shoulder matches the back exactly, so the shoulder seam balances by construction; cut in a fluid fabric for the drape. A soft-goods garment — no hardware. FC-200 long-tail (silhouette gap).

Part of the **Fashion Cabinet Commons** (FC-200, long-tail — everyday silhouette
gap, draped knit). Official visualizer and configurator:
[Fashion Cabinet](https://fashioncabi.net).

> An open, made-to-measure cowl top gets its drape from the front's own folded facing rather than a separate collar, so a draped neckline becomes a single-fabric, easy-to-cut commons object sized to the wearer.
