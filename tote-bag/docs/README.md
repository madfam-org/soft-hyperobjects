# Tote Bag

A classic **boxed-bottom tote**: one wrap body panel (front + base + back cut as one,
folded at the base) that boxes at the lower corners for a flat bottom, plus two carry
straps. An optional length-adjustable strap bridges to the Yantra4D
[`strap-buckle`](https://app.yantra4d.com).

Part of the **Fashion Cabinet Commons** (FC-200, Lane 3 — accessories). Official
visualizer and configurator: [Fashion Cabinet](https://fashioncabi.net).

## Pieces

Body (front + base + back, corners boxed at the base fold) + two carry straps.

## Parameters

`bag_width`, `bag_height`, `bag_depth` (boxed gusset; 0 = flat), `strap_width` (sizes the
Yantra4D buckle slot), `strap_length`, `hem_allowance`.

## Cross-commons bridge

`notion.hardware_ref` → `strap-buckle`, mapping `strap_width → webbing`. Point/slot
attach (no flange), so name + parameter resolution.
