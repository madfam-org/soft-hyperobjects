# One-hand-close wrap shirt

A wrap shirt a person can **close with one hand**: the front crosses over (cache-cœur) and
fastens with magnetic button covers that look like buttons but snap shut with a magnet — no
threading a button through a hole.

Part of the **Fashion Cabinet Commons** (FC-500, rank #438 — adaptive).
**Yantra4D-bridged** (`magnetic-button-cover`). Official visualizer and configurator:
[Fashion Cabinet](https://fashioncabi.net).

## Why it earns its rank

A button through a buttonhole is a two-handed fine-motor task that silently excludes anyone with
hemiplegia, arthritis, a tremor or a single working hand. A cross-front wrap needs no aim: the
fronts overlap over a wide margin and the magnetic covers pull themselves shut. Because they look
like buttons, the wearer is not marked out by adaptive hardware. The aid is in the geometry.

## Pieces

`front` (cut 2, the crossing fronts) + `back` (cut 1 on fold) + `sleeve` (cut 2) + `collar`
(cut 1).

## The seam that solves

The wrap overlap is **clamped under 95 % of the front half** so the wrap can never exceed the
body and fold back on itself, whatever the sliders do. Each front sews to the back at the side
(ease carries the wrap's extra length) and at the shoulder; the sleeve cap is solved to one
front armhole plus the back armhole; the collar length is the measured back-neck run.

## Construction notes

Cut a crisp opaque poplin so the wrap holds flat to close. Interface the diagonal wrap edge so
the magnetic covers sit true. Topstitch the wrap edge so it does not roll. Set five magnetic
button covers along the marked cover line.

## Cross-commons bridge

Yantra4D **`magnetic-button-cover`** (`notion.hardware_ref`): its `button_dia` is driven by this
shirt's `button_diameter`, the same parameter that drives the `wrap_closure` interface — the
dimensional handshake the hardware lane enforces.
