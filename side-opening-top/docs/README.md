# Side-Opening Top

An adaptive pull-on-free top: a relaxed front + back where one side seam and the matching sleeve underarm open fully, closed by a run of magnetic clasps, so the garment can be dressed one-handed or seated without raising the arms overhead. The magnetic-clasp solid bridges to Yantra4D `magnetic-clasp`. Fashion Cabinet owns the garment + clasp placement. FC-200 long-tail (adaptive).

Part of the **Fashion Cabinet Commons** (FC-200, long-tail — adaptive & inclusive /
maternity). Official visualizer and configurator: [Fashion Cabinet](https://fashioncabi.net).

> An open, made-to-measure top that opens fully down one side and closes with magnetic clasps removes the overhead reach and fine-motor fastening a conventional top demands — making dressing independent for people with limited mobility, one working arm, or dexterity differences, from an open pattern anyone can adapt.
