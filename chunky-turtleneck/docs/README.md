# Chunky Roll-Neck Sweater

A heavy drop-shoulder knit pullover finished with a tall **roll-neck** collar — a rib
tube drafted at twice its finished height and folded, whose lower edge equals the
neckline run.

Part of the **Fashion Cabinet Commons** (FC-400, Lane 4 — knitwear depth). Official
visualizer and configurator: [Fashion Cabinet](https://fashioncabi.net).

## Pieces

| Piece | Cut | Notes |
| :-- | :-- | :-- |
| `front` / `back` | 1 on fold each | Drop-shoulder body. |
| `sleeve` | 2 | Straight head solved to the armhole. |
| `roll_neck` | 1 | Tall rib tube, double-height, folded. |
| `cuff` / `hem_band` | 2 / 1 | Rib bands. |

## Solving and clamps

Shoulder run floored at 45 mm; shoulder slope capped at `0.45 × armhole_depth` (the
back-neck-rise clamp lesson). Sleeve head solved to the armhole length, biceps widened so
the crown is never degenerate. Roll-neck length solved from the measured neckline and
floored. Signed knit ease, floored draft girth.

## Declared seams

Armholes ↔ sleeve head edges, `front.side ↔ back.side`, `front.shoulder ↔ back.shoulder`,
sleeve underarm to itself.

## Hardware

**None** — a roll-neck pullover has no closure.
