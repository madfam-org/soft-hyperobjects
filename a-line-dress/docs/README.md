# A-Line Dress — FC-100 #22

Waist-seamless shift-to-flare: a fitted bust region (side-bust darts kept
internal) flaring to an A-line hem `flare_mm` wider than the bust quarter.
Front on fold; back cut 2 with a CB invisible-zipper notch and one fisheye
waist dart per panel. Neck and armhole facings are derived from the measured
openings (neck `2×front.neck + 2×back.neck + 2sa`, cut 1; armhole
`front.armhole + back.armhole + 2sa`, cut 2 — one per armhole). Parameter
contract: `project.json` + the `main.py` docstring.
