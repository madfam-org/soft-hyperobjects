# Collar Stay

A **Yantra4D-bridged notion** — the 2-D placement guide for the tapered blade that keeps a shirt-collar point crisp. Fashion Cabinet owns
the placement; the finding **solid** is the Yantra4D [`collar-stay`](https://app.yantra4d.com)
cartridge, referenced through `notion.hardware_ref`.

Part of the **Fashion Cabinet Commons** (FC-200, Lane 1 — findings). Official visualizer
and configurator: [Fashion Cabinet](https://fashioncabinet.app).

## The cross-commons bridge

`notion.hardware_ref` → `collar-stay`, enforced in CI by `scripts/qa/verify_hardware_links.py`
against the pinned snapshot.

Original draft for Fashion Cabinet. `CERN-OHL-W-2.0`.
