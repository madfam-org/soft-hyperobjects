# Nursing Top

A relaxed nursing top with a double-layer front: an outer front that lifts from the hem over an inner modesty layer with a nursing slit, so a parent can feed discreetly without undressing. A soft-goods garment — no hardware; the access is a marked sewn overlap. FC-200 long-tail (maternity/nursing).

Part of the **Fashion Cabinet Commons** (FC-200, long-tail — adaptive & inclusive /
maternity). Official visualizer and configurator: [Fashion Cabinet](https://fashioncabinet.app).

> An open, made-to-measure nursing top with a double-layer discreet-access front lets a parent feed without undressing, from an open pattern that keeps the maker in control of fabric and fit — nursing wear as a repairable commons object, not a marked-up specialty product.
