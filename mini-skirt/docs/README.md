# Mini Skirt — FC-100 #35

The straight skirt block shortened above the knee and slightly tapered: the
hem half-width pulls in `taper_mm` from the hip half-width, and a CB back
vent (`vent_height` tall, 40 mm underlap, marked as internals on the back
piece) restores the walking ease the taper removes. Front on fold with one
dart per half; back cut 2 with a CB zipper notch and one dart per panel; the
straight cut-1 waistband is sized off the measured waist seam and verified
with an eased multi-edge check. Parameter contract: `project.json` + the
`main.py` docstring.
