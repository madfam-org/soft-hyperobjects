# Waistband Block

Enabler cartridge (not FC-100 counted): a straight fold-over waistband strip, drafted cut-ready — seam allowances included in the rectangle, fold line marked at mid-height, side-seam notch at the bottom edge.
The `bottom` edge is the `waistband` interface: its length is `waist_length` (or `waist_girth + standing_ease` in auto mode) plus both end allowances, ready to bind skirt, trouser, and shorts waist seams.
